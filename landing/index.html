SanderOS EVO — APK del launcher

v1.1.0

El primer binario instalable del sistema: Vista de Conducción con carretera pseudo-3D animada, temas Midnight/Light/Auto con persistencia, gestor de módulos y stub OBD2 que demuestra el contrato completo. Registrado como launcher HOME del sistema.

  • Launcher HOME apaisado · Kotlin + Jetpack Compose
  • APK universal: arm64-v8a, armeabi-v7a, x86 y x86_64
  • Temas Midnight / Light / Auto con persistencia DataStore
  • Gestor de módulos + stub OBD2 con contrato completo
Descargar APK Código fuente

Instalación: copia la APK a la tableta, activa «Orígenes desconocidos» y ábrela con un gestor de archivos. Elige SanderOS EVO como launcher de inicio cuando el sistema lo pregunte.

Android 10+

  4. Elige SanderOS EVO como launcher de inicio.

El rombo de Renault se muestra como máscara CSS y se tiñe con el color de texto de cada tema, igual que ColorFilter.tint del launcher. Designer se incluye solo en peso Regular: el «EVO» lleva bold sintético.
